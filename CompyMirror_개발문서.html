03

버전별 구현 내용

v8
마이크로 인터랙션 레이어
  • micro.css — 뷰파인더 CSS perspective tilt, 버튼 specular sheen (::before radial-gradient), 리플 키프레임, 슬라이더 버블, 카운트다운 spring-pop, 프리셋 chip-pick, 셔터 recoil, 브랜드 hover tilt
  • micro.js — pointermove로 버튼 --mx/--my 업데이트, 마그네틱 버튼 --tx/--ty, pointerdown 리플 spawn, 슬라이더 버블 포지셔닝, MutationObserver로 카운트다운 팝 트리거, window.snap·preset 함수 래핑
  • 기존 글로벌 --mxr / --myr 재활용 → 추가 rAF 루프 없음
  • prefers-reduced-motion 완전 대응 (spatial 효과만 제거, state 피드백 유지)
v9
피드백 · 후원 · 푸터
  • 푸터 바 — .foot-bar glass 컴포넌트, 피드백(ghost) + 후원하기(holo foil) 버튼
  • 피드백 모달 — #feedback-modal, Tally iframe (hideTitle=1&transparentBackground=1), backdrop-click 닫기
  • 후원 모달 — #donate-modal, 카카오페이 QR을 base64로 인라인 (run_script로 이미지 읽어 HTML에 직접 삽입), KakaoPay 배지
  • ESC 키로 두 모달 동시 닫기
v10
UX 수정
  • 투어 자동 실행 제거 — localStorage 체크 후 setTimeout(startTour) 코드 삭제. openGuide()는 ? 버튼에서만 호출
  • 버튼 항상 표시 — 반전·비율·인생네컷·스냅샷에서 style="display:none" 제거. 초기 로드 시 disabled=true, 카메라 시작 시 disabled=false, 카메라 종료 시 다시 disabled=true
  • startCam() / stopCam() 에서 display 토글 대신 disabled 토글로 변경
04

핵심 구현 패턴

① 버튼 Specular Sheen (CSS 변수 + ::before)

/* CSS */ .btn::before { background: radial-gradient(90px circle at var(--mx, 50%) var(--my, 50%), rgba(255,255,255,.55), rgba(255,255,255,0) 62%); mix-blend-mode: soft-light; /* 텍스트 가독성 유지 */ } /* JS — pointermove 핸들러 */ const r = el.getBoundingClientRect(); el.style.setProperty('--mx', ((e.clientX - r.left) / r.width * 100).toFixed(1) + '%'); el.style.setProperty('--my', ((e.clientY - r.top) / r.height * 100).toFixed(1) + '%');

② 카운트다운 Spring-pop (MutationObserver)

/* 텍스트 바뀔 때마다 animation 재실행 */ new MutationObserver(() => { cd.classList.remove('pop'); void cd.offsetWidth; /* reflow 강제 — animation 재시작 트리거 */ cd.classList.add('pop'); }).observe(cd, { childList: true, characterData: true, subtree: true });

③ 기존 함수 래핑 (셔터 리코일)

/* micro.js는 메인 script 이후 로드 → 전역 함수를 래핑 가능 */ ['snap', 'fireFlash'].forEach(fn => { const orig = window[fn]; window[fn] = function() { kick(); return orig.apply(this, arguments); }; });

④ 카카오페이 QR base64 인라인

/* run_script로 이미지 읽어 HTML에 직접 삽입 */ const qrBlob = await readFileBinary('uploads/kakao_qr.png'); const b64 = btoa(String.fromCharCode(...new Uint8Array(await qrBlob.arrayBuffer()))); const qrDataUrl = 'data:image/png;base64,' + b64; /* → img src에 직접 삽입, standalone에서도 외부 요청 없음 */

v7 vs v8 성능 분석

실제 병목 (v7 · v8 동일)

캔버스 픽셀 처리60fps rAF
getImageData / putImageData매 프레임
박스 블러 (JS)O(w×h)

v8 추가 비용

추가 rAF 루프없음
뷰파인더 tiltCSS transform (GPU)
버튼 sheenhover 시 CSS var 2개
리플클릭 시 1회 DOM
결론: v7과 v8의 체감 성능 차이 없음. 모든 마이크로 인터랙션은 GPU 합성 레이어(transform, opacity)만 사용하며 실제 병목(캔버스 픽셀 루프)을 건드리지 않습니다.
