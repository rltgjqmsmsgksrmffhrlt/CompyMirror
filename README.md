# CompyMirror

컴퓨터 내장 웹캠(또는 외장 카메라)을 실시간 거울처럼 사용하는 웹 앱.
별도 설치 없이 브라우저에서 바로 실행되며, 뷰티 필터와 스냅샷 기능을 제공합니다.

## 핵심 가치

- **설치 불필요** — 브라우저 기반, HTML 파일 하나로 동작
- **강력한 프라이버시** — 모든 처리는 로컬에서, 서버 전송 없음
- **뷰티 앱 수준의 필터** — 픽셀 직접 연산 기반 보정

## 주요 기능

| 기능 | 설명 |
|------|------|
| 실시간 거울 | 카메라 영상을 좌우 반전하여 거울처럼 표시 |
| 좌우 반전 토글 | 반전 on/off 전환 |
| 뷰티 필터 | 밝기 · 대비 · 채도 · 따뜻함 · 피부보정 슬라이더 |
| 프리셋 | 내추럴 / 글로우 / 비비드 / 흑백 / 웜톤 / 쿨톤 원클릭 적용 |
| 스냅샷 | 현재 화면(필터 적용 상태)을 PNG로 저장 |
| 카메라 on/off | 사용 후 즉시 스트림 종료 |

## 보안 정책

> **이 앱의 가장 중요한 차별점은 보안입니다.**

- 카메라 영상은 **서버로 전송되지 않습니다**
- 모든 픽셀 연산은 **브라우저 내 Canvas API**에서 수행
- 네트워크 요청 없음 — 완전한 오프라인 동작 가능
- 페이지 이탈 또는 "끄기" 클릭 시 즉시 스트림 종료 (`MediaStreamTrack.stop()`)

## 사용 방법

1. [`CompyMirror_v10_standalone.html`](CompyMirror_v10_standalone.html) 다운로드 (최신 버전)
2. 브라우저에서 열기
3. 카메라 권한 허용
4. 슬라이더 또는 프리셋으로 보정 적용
5. 스냅샷 버튼으로 저장

> 💡 `_standalone.html` 파일은 모든 리소스가 포함된 단일 파일 버전입니다.

## 기술 스택

- 순수 HTML / JavaScript (프레임워크 없음)
- `navigator.mediaDevices.getUserMedia` — 카메라 접근
- `Canvas 2D API` — 렌더링 및 픽셀 연산
- `canvas.toDataURL()` — 스냅샷 저장
