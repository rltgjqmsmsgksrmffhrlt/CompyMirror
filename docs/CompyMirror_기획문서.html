CompyMirror v7 → v10

작성일 2026. 06. 05 버전 v10 기준 분류 기획 / UX / 디자인 결정

CompyMirror 개발 과정에서 이루어진 기능 확장, UX 결정, 디자인 방향을 정리한 기획 문서입니다. 마이크로 인터랙션 도입부터 피드백·후원 기능까지의 의사결정 과정을 담습니다.

01

프로젝트 개요

🪞
무엇인가
웹캠을 거울처럼 사용하는 브라우저 앱. 필터·보정·인생네컷·스냅샷을 로컬에서 처리.
🔒
핵심 원칙
모든 영상·AI 처리가 기기 내부에서만 동작. 서버 업로드 없음. 개인정보 수집 없음.
✦
디자인 언어
Liquid Chrome — 홀로그래픽 포일, 글래스모피즘, 포인터 반응형 광원 효과.
📦
배포 형태
standalone HTML 단일 파일. 외부 의존성 없이 브라우저에서 즉시 실행.
02

개발 범위 (v7 → v10)

버전추가된 기능분류
v7기존 완성본 — 카메라, 필터, 프리셋, 인생네컷, 스냅샷, 코치마크 투어Base
v8마이크로 인터랙션 레이어 (micro.css + micro.js)UX
v9피드백 모달 (Tally), 후원 모달 (카카오페이 QR), 푸터 바기능
v10투어 자동 실행 제거 (? 버튼으로만), 버튼 항상 표시 + disabled 상태UX
03

마이크로 인터랙션 도입 배경

문제 인식: v7에서 배경(홀로·글레어)은 마우스에 반응하지만, 컨트롤 UI 자체는 정적이었다. 로그인 화면처럼 사용자의 작은 행동에 즉각 반응하는 세밀한 피드백이 없었다.
01
뷰파인더 패럴랙스 틸트
커서 위치에 따라 거울 패널이 3D로 기울어짐. 기존 --mxr/--myr CSS 변수를 재활용해 추가 JS 없이 GPU 합성만으로 구현. 실제 반사 패널 같은 물리감 부여.
02
마그네틱 버튼
카메라 시작·스냅샷·인생네컷 등 주요 버튼이 커서에 끌려오는 효과. 중요 액션에 시선을 유도하고 클릭 전 물리적 피드백 제공.
03
리퀴드 리플
모든 버튼·칩·타이머 클릭 시 클릭 지점에서 물결이 퍼짐. "Liquid Chrome" 디자인 언어에서 클릭=액체 반응으로 연결.
04
슬라이더 값 버블
드래그 시 홀로 포일 버블이 썸 위로 팝업. 현재 값을 시각적으로 확인하면서 조절 가능. 썸에 발광 효과 추가.
05
카운트다운 스프링 팝 + 셔터 리코일
카운트다운 숫자가 탄성 있게 팝인. 촬영 순간 뷰파인더 전체가 미세 수축 후 복귀 — 실제 셔터 누르는 느낌 강화.
06
성능 고려
추가 rAF 루프 없음. 모든 애니메이션은 GPU 합성 레이어(transform, opacity)만 사용. 실제 병목(캔버스 픽셀 처리)을 건드리지 않아 v7과 체감 속도 동일.
04

피드백 & 후원 기능 기획

피드백 수집 방식
Tally.so 임베드 (iframe) — 페이지 이탈 없이 모달 내에서 폼 제출. → 백엔드 불필요. DB·이메일 알림 포함. 무료. 한 줄 URL만 교체하면 폼 내용 변경 가능.
후원 결제 방식
카카오페이 QR 모달 — 토스 링크 차단 후 대안 채택. → 한국 유저에게 가장 익숙한 플로우. 외부 서비스 가입 불필요. QR 이미지 하나로 완결.
UI 배치
글래스 푸터 바 — 하단에 고정 배치, 피드백(ghost)·후원하기(holo foil) 버튼. → 메인 기능 방해 없이 존재감. 홀로 포일 버튼으로 후원 유도.
개인정보 처리
QR 이미지에서 이름 제거 — 카카오페이 QR에 표시되던 실명 크롭 처리. → QR 자체는 수취 전용으로 공개 안전. 이름 노출만 차단.
05

주요 UX 결정 사항

이슈결정이유
투어 자동 실행 자동 실행 제거 → ? 버튼 클릭 시만 노출 투어 오버레이가 기능 접근을 막는다는 피드백. 가이드는 선택적으로.
카메라 꺼진 상태의 버튼 반전·비율·인생네컷·스냅샷 항상 표시, disabled 상태로 어떤 기능이 있는지 미리 보여줌. 카메라 켜면 활성화됨을 자연스럽게 전달.
v7 vs v8 성능 체감 차이 없음 — 마이크로 인터랙션은 GPU 레이어만 사용 실제 병목은 getImageData 캔버스 루프. 마이크로 인터랙션은 추가 rAF 없음.
배포 형태 standalone HTML 단일 파일 서버 불필요. Netlify Drop에 파일 하나만 올려도 즉시 배포 가능.
